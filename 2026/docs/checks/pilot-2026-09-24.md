# Single-pass pilot, 2026-09-24

Question: can a page be read in one pass (13 native-resolution strips, no per-word zoom crops)
without losing accuracy, and what does that do to cost? Five verified finals used as ground
truth: p010, p020, p030 (all spot-checked), p057 (hardest reconciliation), p159 (foot block).
Reads ran as Claude Code subagents with `scripts/prompts/read_single.md` (image tools forbidden,
about 20 tool calls each). Reconciliation by one Fable subagent with the standard
`reconcile.md` prompt pointed at `transcription/pilot/opus/`. Per-read scoring is in
`pilot-single-pass.md`; per-read diffs in `pilot-diffs/`.

Reading: the single-pass pair plus reconciler makes about the same number of substantive
errors as the zoom-heavy pipeline did, but of a different kind. It catches wrong sorts the old
pipeline silently normalized (three on three verified pages) and misses fine glyph calls
(period/comma, h/b, e/c, hyphen vs speck) that zooming settled. Sonnet is not usable as a
reader: pair agreement 80–90% (Opus 94–100%), it silently normalizes wrong sorts
(`Sauueur`, `vſer`, `facilement`, `ſeur`), only 13 of 31 shared differences were self-flagged
(Opus: 17 of 22), and one Sonnet read turned a large-type TEXTE quotation into heading blocks.

Residual differences that are conventions, not readings, and can be fixed in the prompt or
`normalize_spacing.py`: space after apostrophe (`d' eſtre`, `qu' Adraſtus`), hyphen in
`faluſt-il`, `pluſque` vs `plus que`, `ANNOT XV.` vs `ANNOT. XV.`.

## Decisions this supports

- Reader: Opus, single pass, two reads per page. Not Sonnet.
- Add a third cheap look for fine glyph classes instead of per-word zooming: the reconciler
  already re-reads every line either reader flags in `uncertain[]` (17 of 22 shared
  differences were flagged); add an explicit zoom budget for line-end hyphen/speck and
  period/comma calls only.
- Reconcile through the API (`scripts/api_reconcile.py`, disputed strips only) once credits
  exist; in the harness, cap the reconciler's image reads.
- Keep spot-checks; the finals themselves carry about one silent wrong-sort per page.
- Proposed fixes to existing finals (need Carson's go-ahead): p010 `toures`, p010 `noſtré`,
  p159 `noraire`.
