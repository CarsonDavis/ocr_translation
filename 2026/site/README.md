# site/

What the viewer serves. Two directories, generated by two scripts, with opposite
rules about git.

## `site/data/` — committed

The page text, as JSON: `book.json`, `index.json`, and `pages/<id>.json`.
Generated by `scripts/split_pages.py` from `manifest.json` and
`transcription/final/`. Small enough to live in the repo, and it is committed, so
a checkout can run the viewer without rebuilding anything.

```
uv run --with jsonschema python scripts/split_pages.py
```

The shape of these files is the page/site data contract, documented in
[`docs/site-data-contract.md`](../docs/site-data-contract.md).

## `site/img/` — gitignored

One image per page: `site/img/<id>.webp`, at the full resolution of the crop
(p004 is 2805 x 3962). Generated by `scripts/site_images.py` from `pages/full/`
with `cwebp -q 70 -m 6` — about 0.9 MB a page, 150 MB for all 162. Far too big
for the repo, so `2026/site/img/` is in `.gitignore` and the images are rebuilt
or downloaded rather than cloned.

```
uv run python scripts/site_images.py
```

A rerun only converts pages whose `.jpg` is newer than their `.webp`, so
recropping one page costs one conversion. `--only p004,p005` narrows it further,
`--quality` overrides q70.

### Uploading

The script prints the sync command it would run. To run it from the script,
pass `--upload` with a bucket and a profile:

```
uv run python scripts/site_images.py --upload --bucket BUCKET --profile PROFILE
```

which is the same as:

```
aws s3 sync site/img/ s3://BUCKET/martin-guerre/img/ \
  --profile PROFILE \
  --cache-control "public, max-age=31536000, immutable" \
  --content-type image/webp \
  --size-only
```

The images never change once a page is final, hence the immutable one-year
max-age; `--size-only` keeps a rerun from re-uploading 150 MB because the mtimes
moved. `--slug` changes the `martin-guerre/` prefix.

## Running the viewer locally

The viewer itself lives outside this repo, in
`~/github/code-by-carson/translations/viewer/`, with `data` and `img` symlinks
pointing back here. Serve that directory:

```
cd ~/github/code-by-carson/translations/viewer
python3 -m http.server 8765
```

and open <http://localhost:8765/#p004>. The hash is the page id, so any
`#<id>` from `site/data/index.json` opens that page.
